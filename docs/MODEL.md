# 모델과 데이터 분할

## 데이터

Binance USD-M 공개 REST의 `exchangeInfo`와 `klines`를 사용합니다. 현재 수집 코드는 `requests`로 직접 요청합니다. 거래소 API 키나 주문 권한은 사용하지 않습니다.

| 시간봉 | 최초 수집 기간 | 방향·구간 모델 재학습 주기 | 개발 검증 초기 학습 / 평가 간격 |
| --- | --- | --- | --- |
| 15분 | 365일 | 1일 | 180일 / 30일 |
| 1시간 | 3년 | 1일 | 365일 / 60일 |
| 4시간 | 5년 | 7일 | 2년 / 90일 |
| 1일 | 7년 | 30일 | 2년 / 180일 |

수집 기간은 요청 기준입니다. 상장 시점에 따라 실제 데이터는 더 짧을 수 있습니다. 최초 수집 이후에는 새 종료 캔들을 추가하며, 기존 이력을 자동으로 잘라내지는 않습니다.

## 입력 피처 22개

| 묶음 | 피처 |
| --- | --- |
| 가격 변화 | `return_1`, `return_3`, `return_12`, `rsi_14` |
| 캔들 모양 | `range_ratio`, `upper_wick_ratio`, `lower_wick_ratio`, `close_position`, `streak_count` |
| 거래량 | `volume_change`, `volume_zscore_20`, `up_volume_ratio_10` |
| 변동성 | `volatility_20`, `atr_14_ratio`, `bb_pct`, `parkinson_vol_20` |
| 추세 | `close_ema_50_ratio`, `close_ema_200_ratio` |
| 시간 주기 | `hour_sin`, `hour_cos`, `day_sin`, `day_cos` |

숫자는 일수가 아니라 선택한 시간봉의 캔들 개수입니다. EMA 200은 4시간봉에서는 200개의 4시간봉을 뜻합니다. 시간·요일 피처는 한국 시간을 기준으로 계산합니다.

## 방향 모델

타깃은 `다음 종가 / 현재 종가 - 1 > 0`입니다. 마지막 행은 다음 종가가 없어 학습에서는 제외하지만 최신 예측의 입력으로 사용합니다. 최신 행의 피처를 계산할 수 없으면 과거 행으로 대체하지 않고 오류를 반환합니다.

학습에 사용할 과거 데이터를 시간순으로 네 구간에 나눕니다.

1. 약 70%: XGBoost 학습.
2. 약 15%: 네 가지 설정의 AUC·Log Loss와 조기 종료를 기준으로 모델 선택.
3. 약 7.5%: 확률 보정기 학습.
4. 약 7.5%: 보정 방법과 LONG·SHORT·NEUTRAL 임계값 선택.

각 경계에서는 다음 봉의 정답이 겹치지 않도록 한 행을 제외합니다. 설정을 고른 뒤 1·2번 구간을 합쳐 분류 모델을 다시 학습합니다. 보정 방법은 원래 확률, sigmoid, isotonic 중 Brier Score와 Log Loss로 고릅니다. 보정기 학습 구간에 한 종류의 정답만 있으면 원래 확률을 사용합니다.

임계값 후보는 0.52~0.60입니다. 상승 확률이 임계값 이상이면 LONG, `1 - 임계값` 이하면 SHORT, 그 사이면 NEUTRAL입니다. 임계값은 선택 구간의 간이 수수료 모의시험으로 고르며, 이 계산은 아래 고정 계약 백테스트와 동일한 체결 모형은 아닙니다.

## 검증

방향 모델은 최근 90일을 최종 평가용 Lockbox로 분리합니다. 나머지 구간에서 과거 학습 범위를 늘려가며 이후 구간을 평가하는 Expanding Walk-Forward를 실행합니다. 각 평가 구간의 예측을 모아 AUC, Log Loss, Brier Score, 전략 성과를 계산합니다.

최종 평가는 웹의 확인란을 선택한 뒤 별도로 실행합니다. 저장된 결과가 있으면 기본적으로 재사용합니다. 다만 별도 최신 예측 모델은 가용 이력을 사용하므로, 이 절차만으로 그 기간이 연구자에게 완전히 미공개였다고 보장할 수는 없습니다. 이미 살펴본 기간의 성과를 보고 설정을 다시 고르면 독립적인 최종 평가가 아닙니다.

이전 모델이나 계산 버전으로 만든 최종 평가 파일은 보존합니다. 이때는 구버전이라는 안내만 표시하고, 과거 성과 수치를 현재 결과로 보여주거나 자동으로 재평가하지 않습니다.

가격 구간 모델은 별도 연구 설계 파일에 Holdout 날짜를 고정합니다. 연구 명령은 기본적으로 최종 평가까지 실행하므로, 개발 검증만 하려면 `--skip-final` 옵션을 사용합니다.

## 가격 구간과 모의 거래

분위수 모델은 같은 피처로 다음 종가 수익률의 Q10·Q50·Q90을 추정합니다. 이를 현재 종가에 적용해 가격으로 표시합니다. Q10~Q90은 목표 포함률 80%의 구간이며 가격 상한·하한이나 장중 고가·저가 예측이 아닙니다.

검증 백테스트는 같은 신호가 이어지는 동안 계약 수량을 유지하고, 신호 변경이나 데이터 공백에서 청산·재진입합니다. 마지막 포지션은 평가 종료 시 청산합니다. 자산이 0이 되면 이후 거래를 중단합니다. 거래소의 실제 유지증거금·강제청산·펀딩비를 재현하는 엔진은 아닙니다.

`paper_trading_model_a/predictions.csv`는 예측별 결과를 나중에 대조하기 위한 기록입니다. 이 파일의 봉별 수수료·수익률은 고정 계약 백테스트와 계산 방식이 달라 동일한 전략의 누적 실적으로 비교하지 않습니다.
