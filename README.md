# jun_crypto

**코인의 가격이 다음 구간에 오를 가능성을 계산하고, 결과를 웹 화면으로 보여주는 개인 프로젝트입니다.**

비트코인 같은 코인과 확인할 시간 간격을 고르면 가격 차트, 상승·하락 확률, 예상 가격 범위를 볼 수 있습니다. 실제 매매를 실행하는 기능은 없습니다.

---

## 어떻게 작동하나요?

Binance에서 과거 가격과 거래량을 가져오고, 이 데이터를 학습한 모델로 다음 구간의 가격 움직임을 예측합니다. 예를 들어 4시간을 선택하면, 다음 4시간 구간이 끝날 때 가격이 현재 기준 가격보다 높을 가능성을 계산합니다.

데이터를 가져오는 것부터 예측 결과를 화면에 보여주는 과정까지 연결해봤으며, 구현 과정에서 AI 개발 도구를 활용했습니다. 예측이 실제 결과와 얼마나 맞는지 과거 데이터로 확인하는 기능도 있습니다.

## 실행하기

Python 3.11 또는 3.12가 필요합니다. macOS에서는 프로젝트 폴더의 터미널에서 아래 명령을 실행합니다.

```bash
bash start.command
```

브라우저에서 [http://127.0.0.1:8000](http://127.0.0.1:8000)을 열고, 코인과 시간 간격을 고른 뒤 **최신 예측 확인**을 누르면 됩니다. 처음에는 데이터를 내려받고 모델을 학습하므로 시간이 걸릴 수 있습니다.

예측은 틀릴 수 있으며, 표시된 확률이 수익을 보장하지는 않습니다.

자세한 내용: [모델 설명](docs/MODEL.md) · [테스트](VERIFICATION.md) · [배포 방법](RENDER_DEPLOY.md)
